Secure connection setup

Your API key belongs in Supabase Edge Function secrets, never in this page or a public repository.

  1. Open your NIPOST developer dashboardCreate or copy your API key from Settings → API Keys.Open developer dashboard ↗
  2. Set the backend secretIn Supabase → Edge Functions → Secrets, add:POSTCODE_API_KEY=your_secret_key
  3. Deploy the Edge FunctionDeploy trustpostcode-api from the supplied project folder.
  4. Configure this appSet the Supabase project URL and anon/publishable key in app.js.
Do not paste your private NIPOST key into chat, HTML, JavaScript, GitHub, or a screenshot.

BUILD WITH TRUSTPOSTCODE

Developer documentation.

The essentials for running the prototype and enabling live lookups.

⌘

1. Configure Supabase

Create a Supabase project, enable Email authentication and run the supplied SQL schema in the SQL Editor.

supabase-schema.sql
⚡

2. Deploy the API function

Set POSTCODE_API_KEY as a Supabase secret, then deploy the Edge Function.

supabase/functions/trustpostcode-api/index.ts
◈

3. Configure the frontend

Set your Supabase URL and anon key in app.js. The frontend invokes the function using the signed-in user's session.

SUPABASE_URL · SUPABASE_ANON_KEY
✓

4. Test live lookup

Sign in, switch off demo mode and run a Level 1 lookup. Higher levels require the relevant API entitlement.

Postcode format

A Nigerian postcode uses five segments: state (2 letters), LGA (2 digits), district (3 alphanumeric), area (2 letters), and building unit (2 digits).

EK-01-A03-FK-01
Illustrative format from official documentation: EK-01-A03-FK-01.
